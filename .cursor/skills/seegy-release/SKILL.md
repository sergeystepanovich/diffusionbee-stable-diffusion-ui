# SEEGY release pack

## Steps

1. Read `seegy/BRAND.md`.
2. Confirm with available facts: title, mix versions, collaborators, label, date, platforms.
3. Produce the pack below in the user's language (RU or EN). Keep track titles in English.

## Deliverables

### 1. Press one-liner (1 sentence)

Title + genre cue + label + optional collab.

### 2. Short announcement (3–5 lines)

Hook → what/when/where → CTA.

### 3. Instagram / Telegram caption

Hook line, 1–2 fact lines, CTA, 5–8 relevant hashtags max (no spam).

### 4. Stories / short post

≤ 90 characters + CTA.

### 5. Platform blurbs

- Spotify Canvas / playlist pitch: 1–2 sentences
- Beatport description: factual, genre tags Progressive House / Melodic Techno

### 6. Missing data checklist

List any missing links or dates as `TODO:` — do not invent them.
